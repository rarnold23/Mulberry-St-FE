LiveStreamCrop Component Examples

Examples of how to use the LiveStreamCrop component to replace EarthCam with YouTube livestreams.

1. Basic Implementation (Replaces EarthCam)

Simple implementation with default settings. This replaces the current EarthCam video in the header image area.

<!-- HTML Structure --> <div id="header-image"></div> <!-- JavaScript Initialization --> <script> new LiveStreamCrop('header-image', { videoId: 'GJFHpFppy2k', width: 425, height: 239, responsive: false }); </script>

2. Responsive 16:9 Aspect Ratio

Automatically maintains 16:9 aspect ratio while keeping the same crop settings across all screen sizes.

<div id="responsive-example"></div> <script> new LiveStreamCrop('responsive-example', { videoId: 'GJFHpFppy2k', responsive: true, offsetX: -10, offsetY: -15, scale: 1.2 }); </script>

3. Using Crop Presets

Pre-configured crop settings for common scenarios like hiding black bars or removing UI elements.

<!-- Hide black bars --> <div id="hide-bars-example"></div> <script> const hideBarsPreset = LiveStreamCrop.CropPresets.hideBlackBars; new LiveStreamCrop('hide-bars-example', { videoId: 'GJFHpFppy2k', width: 400, height: 300, ...hideBarsPreset }); </script>

4. Using Data Attributes (Auto-initialization)

Initialize components automatically using data attributes without JavaScript.

<div data-livestream-crop data-video-id="GJFHpFppy2k" data-width="500" data-height="300" data-offset-x="-20" data-offset-y="-10" data-scale="1.3" data-responsive="true" ></div>

5. Custom Styling with CSS Variables

Customize the appearance using CSS variables for easy theming.

<style> .custom-livestream { --livestream-border-radius: 12px; --livestream-background: linear-gradient(135deg, #1a1a1a 0%, #2a2a2a 100%); box-shadow: 0 4px 20px rgba(0,0,0,0.3); } </style> <div id="custom-example" class="custom-livestream"></div> <script> new LiveStreamCrop('custom-example', { videoId: 'GJFHpFppy2k', width: 450, height: 250 }); </script>

6. React Component Usage

How to use the React version of the component.

import LiveStreamCrop from './LiveStreamCrop.jsx'; function App() { return ( <div> <LiveStreamCrop videoId="GJFHpFppy2k" width={425} height={239} offsetX={-10} offsetY={-15} scale={1.2} responsive={true} className="custom-livestream" /> </div> ); } // Using crop presets const { hideBlackBars } = LiveStreamCrop.CropPresets; <LiveStreamCrop videoId="GJFHpFppy2k" width={400} height={300} {...hideBlackBars} />

Integration Guide: Replacing EarthCam

To replace the current EarthCam implementation in your site:

  1. Include the component files:
    <link rel="stylesheet" href="styles.css"> <script src="live-stream-crop.js"></script>
  2. Replace the EarthCam initialization in unified-player.js:
    // Replace this line in loadEarthCamStream(): // window.earthcamStream = new EarthCamStream('header-image', {...}); // With this: window.liveStreamCrop = new LiveStreamCrop('header-image', { videoId: 'GJFHpFppy2k', width: 425, height: 239, offsetX: -10, // Adjust to crop as needed offsetY: -15, // Adjust to crop as needed scale: 1.2, // Adjust zoom level responsive: false });
  3. Remove EarthCam dependencies:
    // Remove these lines from index.html: // <script src="earthcam-stream.js"></script> // <script src="https://cdn.jsdelivr.net/npm/hls.js@latest"></script>

Crop Adjustment Guide

How to adjust the crop settings for different scenarios:

  • Hide black bars: Use negative offsetY values (-10 to -20) and scale > 1
  • Center on specific area: Use offsetX and offsetY to shift the view
  • Remove YouTube UI: Use offsetY: -10 and scale: 1.2
  • Zoom in on center: Use scale > 1 with small offset values
// Common crop scenarios: LiveStreamCrop.CropPresets.hideBlackBars // { offsetX: 0, offsetY: -12.5, scale: 1.25 } LiveStreamCrop.CropPresets.centerRegion // { offsetX: -25, offsetY: -25, scale: 1.5 } LiveStreamCrop.CropPresets.zoomCenter // { offsetX: -12.5, offsetY: -12.5, scale: 1.25 } LiveStreamCrop.CropPresets.removeUI // { offsetX: 0, offsetY: -10, scale: 1.2 }
